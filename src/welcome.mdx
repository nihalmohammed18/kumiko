# Kumiko

A playful React component library in the spirit of Duolingo. Buttons press down onto a darker edge, type is round
and chunky, colours are bright, and three characters, Pip, Mori and Tuck, cheer people on when they finish
something. It's built on Base UI and Tailwind CSS v4, it's accessible, and it works in dark mode and right to left.

## Install

```sh
npm install kumiko-ui
```

Then follow the [setup steps in the README](https://github.com/nihalmohammed18/kumiko#install-and-set-up).
Coding agents can read `node_modules/kumiko-ui/llms.txt`.
